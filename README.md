# UniQuest

UniQuest is a fantasy-themed academic progress tracker built with HTML, CSS, and JavaScript. The project turns study progress into an adventure-style interface where students can view their academic realm, manage quests, and receive guidance from an oracle page.

## Pages

- `Realm Map` - Main dashboard showing the learner profile, XP progress, realm status, and semester path.
- `Quest Log` - Displays active and completed academic quests with XP rewards.
- `Academic Oracle` - Provides a daily academic prompt, hint, answer reveal, and preparation checklist for the next realm.

## How To Run

Open `realm.html` in a browser to start from the main Realm Map page.

From the navigation bar, you can move between:

- Realm Map
- Quest Log
- Academic Oracle

No build tools or installations are required.

## Features

- Connected navigation across all three pages
- Presentable UniQuest branding with a shared logo
- XP and quest progress display
- Realm progression cards
- Interactive quest buttons
- Oracle hint and answer reveal
- Bridge checklist for next-semester preparation
- Responsive layout styling for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project presents academic tasks as an adventure game interface, making learning progress feel more visual, motivating, and organized.
